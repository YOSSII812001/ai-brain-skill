# Synthesis（統合分析）作成アルゴリズム

## トリガー条件（いずれか1つ満たせば作成検討）

1. **3+ソース収束**: 同一タグを共有するsourceが3件以上存在
2. **クロスリンク密度**: 3+conceptが相互にwikilinkで接続されているクラスター
3. **Query頻度**: outputs/で同一テーマに関するqueryが2回以上出現
4. **矛盾集積**: 同一トピックで⚠️フラグが2件以上

## テンプレート

```markdown
---
title: "統合分析タイトル"
date_created: YYYY-MM-DD
date_modified: YYYY-MM-DD
summary: "1行要約"
tags: []
type: synthesis
status: draft
sources: ["[[source-1]]", "[[source-2]]", "[[source-3]]"]
---
# タイトル

## 概要
[この統合分析が扱うテーマと意義]

## 横断的知見
[複数ソースを横断して見えるパターン・トレンド]

## 比較分析
[ソース間の共通点・相違点・矛盾]

## 結論と含意
[統合から導かれる洞察]

## 関連概念
- [[concept]] — 関連性の説明

## ソース
- [[source-1]]: 該当箇所の要約
- [[source-2]]: 該当箇所の要約
- [[source-3]]: 該当箇所の要約
```

## 注意事項

- ソースに明示的に裏付けられた接続のみを記述（根拠なき接続は禁止）
- 矛盾がある場合は⚠️付きで両論併記
- 既存synthesesとの重複を確認してから作成
